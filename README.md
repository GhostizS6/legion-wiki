# legion-wiki

Енциклопедія предметів гри «Легион» (`legiongame.gg/c/<channel>/`) з вкладкою **«Вики»**
прямо в шапці гри та автоматичним збором даних.

- Розширення MV3, працює тільки на `https://legiongame.gg/c/*`.
- Каталог лежить у `data/items.json` і роздається через GitHub:
  `https://raw.githubusercontent.com/GhostizS6/legion-wiki/main/data/items.json`.
- Розширення тягне свіжі дані у фоні (кеш 6 годин) і має локальний снепшот
  `extension/data/items.json` на випадок відсутності мережі.

## Структура

| Шлях | Що це |
|---|---|
| `data/items.json` | єдине джерело правди: 315 предметів, іконки — inline SVG |
| `extension/` | MV3-розширення |
| `extension/content/collector.js` | MAIN world: перехоплює `LGInventory.art` і `/api/me` |
| `extension/content/boot.js` | вкладка «Вики», shadow DOM, зв'язок з фоном |
| `extension/content/app.js` | UI вікі (пошук, фільтри, рейтинг, заточка, порівняння) |
| `extension/shared/merge.js` | злиття каталогу зі спостереженнями (спільне для фону і Node) |
| `tools/seed.js` | одноразовий імпорт старого снепшоту вікі 3.13.0 |
| `tools/merge.js` | злити експорт із гри у `data/items.json` |
| `tools/validate.js` | перевірка даних і синхронності снепшоту |
| `tools/test-merge.js` | тест логіки злиття |

## Встановлення

1. `edge://extensions` → увімкнути **режим розробника**.
2. **Завантажити розпаковане** → вибрати папку `extension`.
3. Відкрити гру: у шапці з'явиться вкладка **Вики**.

Після зміни коду — кнопка «Оновити» на картці розширення і перезавантаження
вкладки гри. Дані оновлюються без перевстановлення.

## Як збираються дані

1. `collector.js` (MAIN world) обгортає `window.LGInventory.art` — сайт сам викликає
   його для кожного показаного предмета. Звідти приходять повний об'єкт предмета
   та його SVG-іконка (`still()` прибирає анімації).
2. Додатково раз на 2 хвилини читається `/api/me` → `hero.items` (усі предмети
   в сумці, навіть не показані на екрані).
3. Фон зберігає спостереження в `chrome.storage.local` (ключ `captures`).
4. Вкладка «Вики» показує каталог, уже злите з цими спостереженнями.
5. **Экспорт JSON** у панелі віддає `legion-wiki-captures.json`.

## Оновлення каталогу в репозиторії

```powershell
node tools/merge.js legion-wiki-captures.json   # злити експорт у data/items.json
node tools/validate.js                          # перевірка + синхронність снепшоту
node tools/test-merge.js                        # тест злиття
git add data extension/data && git commit -m "data: update items"
git push
```

`tools/merge.js` сам копіює `data/items.json` у `extension/data/items.json`.
Після `git push` розширення побачить нові дані протягом 6 годин
(або одразу — кнопкою «Обновить данные»).

## Правила даних

- Ключ предмета — `gameId + '|' + name`. Однакові id і назва → оновлюється
  останнє спостереження; інша назва того ж `gameId` — окремий запис
  (успадковує опис базового предмета).
- `stats` — словник російськими назвами характеристик:
  `{ "Царапки": { "value": 12, "percent": false } }`.
- `icon` — або рядок `<svg …>`, або `data:`-URI; UI сам робить data-URI.

## Обмеження

- Збирається тільки те, що потрапило в гру: власний інвентар, торгові вікна,
  пошта. Предмет, якого ніхто не показував, лишиться без статів та іконки.
- `LGInventory.art` — внутрішній API сайту. Якщо гра його перейменує, збір
  іконок зупиниться (дані з `/api/me` при цьому продовжать збиратись).
- Розширення саме себе не оновлює: новий код = переустановка папки,
  нові предмети = коміт у `data/items.json`.
