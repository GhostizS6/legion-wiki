# legion-wiki

Энциклопедия предметов игры «Легион» (`legiongame.gg/c/<channel>/`) с вкладкой **«Вики»**
прямо в шапке игры и автоматическим сбором данных.

- Расширение MV3, работает только на `https://legiongame.gg/c/*`.
- Каталог лежит в `data/items.json` и раздаётся через GitHub:
  `https://raw.githubusercontent.com/GhostizS6/legion-wiki/main/data/items.json`.
- Расширение тянет свежие данные в фоне (кеш 6 часов) и имеет локальный снепшот
  `extension/data/items.json` на случай отсутствия сети.

## Структура

| Путь | Что это |
|---|---|
| `data/items.json` | единственный источник правды: 315 предметов, иконки — inline SVG |
| `extension/` | MV3-расширение |
| `extension/content/collector.js` | MAIN world: перехватывает `LGInventory.art` и `/api/me` |
| `extension/content/boot.js` | вкладка «Вики», shadow DOM, связь с фоном |
| `extension/content/app.js` | UI вики (поиск, фильтры, рейтинг, заточка, сравнение) |
| `extension/shared/merge.js` | слияние каталога с наблюдениями (общее для фона и Node) |
| `tools/seed.js` | одноразовый импорт старого снепшота вики 3.13.0 |
| `tools/merge.js` | слить экспорт из игры в `data/items.json` |
| `tools/validate.js` | проверка данных и синхронности снепшота |
| `tools/test-merge.js` | тест логики слияния |

## Установка

1. `edge://extensions` → включить **режим разработчика**.
2. **Загрузить распакованное** → выбрать папку `extension`.
3. Открыть игру: в шапке появится вкладка **Вики**.

После изменения кода — кнопка «Обновить» на карточке расширения и перезагрузка
вкладки игры. Данные обновляются без переустановки.

## Как собираются данные

1. `collector.js` (MAIN world) оборачивает `window.LGInventory.art` — сайт сам вызывает
   его для каждого показанного предмета. Оттуда приходят полный объект предмета
   и его SVG-иконка (`still()` убирает анимации).
2. Дополнительно раз в 2 минуты читается `/api/me` → `hero.items` (все предметы
   в сумке, даже не показанные на экране).
3. Фон сохраняет наблюдения в `chrome.storage.local` (ключ `captures`).
4. Вкладка «Вики» показывает каталог, уже слитый с этими наблюдениями.
5. **Экспорт JSON** в панели отдаёт `legion-wiki-captures.json`.

## Обновление каталога в репозитории

```powershell
node tools/merge.js legion-wiki-captures.json   # слить экспорт в data/items.json
node tools/validate.js                          # проверка + синхронность снепшота
node tools/test-merge.js                        # тест слияния
git add data extension/data && git commit -m "data: update items"
git push
```

`tools/merge.js` сам копирует `data/items.json` в `extension/data/items.json`.
После `git push` расширение увидит новые данные в течение 6 часов
(или сразу — кнопкой «Обновить данные»).

## Правила данных

- Ключ предмета — `gameId + '|' + name`. Одинаковые id и название → обновляется
  последнее наблюдение; другое название того же `gameId` — отдельная запись
  (наследует описание базового предмета).
- `stats` — словарь с русскими названиями характеристик:
  `{ "Царапки": { "value": 12, "percent": false } }`.
- `icon` — либо строка `<svg …>`, либо `data:`-URI; UI сам делает data-URI.

## Ограничения

- Собирается только то, что попало в игру: собственный инвентарь, торговые окна,
  почта. Предмет, который никто не показывал, останется без статов и иконки.
- `LGInventory.art` — внутренний API сайта. Если игра его переименует, сбор
  иконок остановится (данные из `/api/me` при этом продолжат собираться).
- Расширение само себя не обновляет: новый код = переустановка папки,
  новые предметы = коммит в `data/items.json`.
